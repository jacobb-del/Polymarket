Project goal:
Build a beginner-friendly Python MVP for scanning Polymarket markets for pre-resolution repricing opportunities.

Important constraints:
- no live trading in v1
- no order placement in v1
- alerts and paper trading only
- prioritize readability and reliability over complexity
- assume the repo owner is not a programmer
- always document assumptions
- keep setup simple
- prefer small verifiable steps
- if Polymarket API details are uncertain, isolate the uncertainty and document it clearly instead of faking certainty

Coding preferences:
- Python 3.11+
- modular code
- SQLite
- .env configuration
- clear README
- simple CLI
- logging and error handling included
